# Progression Principles

The [placements chapter](/docs/music/placements) laid out the relationships of placements from a given key.
In the [preference chapter](/docs/music/preference) we proposed a principle of preference for small primes in the WPL, 
explaining dissonance of lcm 15 and 20 as well as why the isomorphic lcm families sound similar regardless of voicing.

Thus far we have mostly been looking at static harmony, i.e. various block chords, with limited melody.
Let's now turn to more dynamic harmony using series of chords, also known as chord progressions.

While any two chords can be played one after another, some seem to fit better together -
surely there are reasons for phenomena such as cadences, circle of fifths and 3-chord-songs (e.g. C, F, G). 
If we can define principles based on physical features which recover popular progressions, 
we might glean some insight into the inner workings of music and then extrapolate from those principles to aid in composition.

## The Principles of Chord Progressions

We can define a chord progression as a triplet of placements. 
Given an origin chord and a target chord, a progression is a triplet of placements consisting of origin-, bridge-, and target-placement:
* The origin placement contains the origin chord.
* The target placement contains the target chord.
* The bridge placement fulfills some progression principle.

The extended placement graphs show that an important relationship between LCMs is not only shared lcm
supersets (e.g. 8@0 contains 4@0 and 4@5) but also shared lcm subsets (e.g. 18@2 bridges 15@11 and 24@0,7). 
This motivates two potential principles:

* **Superset Principle** — Chord A can progress to chord B if A shares an lcm superset with B.
* **Subset Principle** — Chord A can progress to chord B if A shares an lcm subset with B.

We previously discussed stability of placements with lcm 15 collapsing to 24 as well as isomorphisms collapsing to representatives (and likely 20@k collapsing to 15@k+7).
In the context of progressions, such stability may play a role - e.g. perhaps the target placement must be stable given the target chord, but the bridge and origin need not be.

Regarding the subset principle, one wonders to what extent subsets are allowed, as a lot of dyads can serve as shared subsets but perhaps larger lcm families are privileged in this regard.

A concrete example of the **superset** principle for the chord progression C to Eb (4@0 → 4@3):

* C is part of 15@7 (4@0 ≅ 3@7), Eb = 4@3 is part of 18@10.
* Placement 15@7 is an lcm superset of 18@10.
* Both C and Eb then share the superset 15@7 and the superset principle thus allows this progression.

In this way, although `{0 4 7}` (3@7) is not a subset of `{0 3 5 7 8 10}` (18@10) since they do not
share key 4, it is still possible to move to 18@10 since 3@7 is part of its superset lcm family 15@7.

Notably 4@3 is also part of 15@7, but since key 4 collapses 15@7 it is not a stable target.
An alternative explanation for 4@0 → 4@3 is that both are part of 20@0. 
However, lcm 20 seems quite unstable and likely collapses to its superset 15@7.
This in turn collapses with key 4, part of the target chord, making this progression seem unlikely.

Of further interest here is that the root key for Eb, key 3, is the collapsing key for 15@7.
While not useful for sustaining melody or chords, perhaps the collapsing key still allows us to go to 18@10 when progressing chords.

There are also subset motivations for 4@0 -> 4@3 such as 15@7->4@3->15@10 where the target chord is also used as the bridge, contained by both 15@7 and 15@10.

A concrete example of the **subset** principle for the chord progression C to Db (4@0 → 4@1):

* C is part of 15@7 (4@0 ≅ 3@7), Db = 4@1 is part of 24@8.
* Placements 15@7 and 24@8 are both lcm supersets of 18@10.
* The subset principle thus allows a progression from 3@7 (15@7) to 4@1 (24@8) via the shared subset
  18@10.

## Scales from the Subset Principle
In the preference chapter we touched on the non-lcm scales of blues and harmonic minor, which produce coherent melodies while being neither lcm sets nor subsets.
Instead they appear to be composed of adjacent lcm scales, producing pragmatic key sets for rapid modulation of melody.

We can make this precise with the subset principle.
Given two placements `P_A`, `P_B` sharing a subset `S ⊆ P_A ∩ P_B`, we can define a scale `P_A ∪ P_B`. 
We can call this a **junction scale** — a pitch set sitting at the junction of two placements that the subset principle bridges.

Using the [`table junction-scales`](/docs/cli/reference#junction-scales) command we can enumerate junction scales.
However, not every shared subset is equally interesting. 
A dyad or triad bridge is satisfied by almost any pair of placements, so the union balloons into a chromatic cluster. 
Looking instead at large shared subsets with the `--min-subset-notes 6` option yields:

```
Scale                         Size  P_A·S·P_B
{0, 1, 3, 5, 6, 9, 10}          7   15@0·18@3·24@1     ← harmonic minor
{0, 1, 3, 5, 7, 9, 10}          7   15@0·18@3·24@8     ← melodic minor
{0, 2, 4, 5, 7, 9, 10, 11}      8   24@0·18@7·24@5     ← bebop dominant (contains blues)
```

Each row is a concrete 12-tet key set with its size and the `P_A·S·P_B` constituents that produced it. 
The rows are specific anchorings; the same necklace recurs at other anchors and the default option `--dedupe-transposition` keeps one representative per necklace. 

Another important default option is the `--stable` option which removes collapsing keys from the final sets. 
For example `15@0·18@3·24@8` contains no key 8 because it collapses the constituent `15@0`.

In the table we see two classical minor scales — **harmonic minor** and **melodic minor**.
We also see the **bebop dominant** scale, which contains blues as a subset.

Investigating smaller bridges produces the harmonic major at `--min-subset-notes 4`. 
Going lower still produces no obvious traditional scales.

### Harmonic minor as a junction
Looking at the first row of the intro table we have: `P_A = 15@0 = {0 1 3 5 8 9 10}` and
`P_B = 24@1 = {0 1 3 5 6 8 10}`. They share the subset `S = 18@3 = {0 1 3 5 8 10}` — their common
parent. Their union is

$$
15@0 \cup 24@1 = \{0\;1\;3\;5\;6\;8\;9\;10\}
$$

This however includes the collapse key `8` of `15@0`. Removing it produces

$$
15@0 \cup 24@1 \;\setminus\; \{8\} \;=\; \{0\;1\;3\;5\;6\;9\;10\} \;=\; \mathrm{harm}@10.
$$

Because `24@1` also contains key `8` the drop has to apply to the finished union, not just to the
`15@0` side, producing harmonic minor.

### Melodic minor as a junction

From the extended triad placement graph we see that 15@k relates to 24@(k+1), 24@(k+8) and 18@(k+3).
At `k = 0` this gives `15@0` *two* `lcm-24` partners sharing the same `18@3` parent. 
Harmonic minor used `24@1` (the `k+1` partner). The `k+8` partner `24@8` is the sibling junction:

$$
15@0 \cup 24@8 \;\setminus\; \{8\} \;=\; \{0\;1\;3\;5\;7\;9\;10\} =\mathrm{mel}@10
$$

This set is the **melodic minor** (ascending). So the two `lcm-24` partners of `15@0` hand us the
two classical minor scales — harmonic minor via `24@1`, melodic minor via `24@8`.

### Bebop dominant and blues

Take `P_A = 24@0 = {0 2 4 5 7 9 11}` and `P_B = 24@5 = {0 2 4 5 7 9 10}`, sharing `S = 18@7 = {0 2 4 5 7 9}`:

$$
24@0 \cup 24@5 = \{0\;2\;4\;5\;7\;9\;10\;11\}
$$

This necklace is the [**bebop dominant**](https://en.wikipedia.org/wiki/Bebop_scale#Bebop_dominant_scale) — a major scale with an added flat seventh.

Blues itself does *not* come straight out of a union. Anchored to match the row above,
`blues@7 = {2 4 7 9 10 11}` keeps *fewer* keys than the bebop-dominant union `{0 2 4 5 7 9 10 11}`:
it drops keys `0` and `5`, the root notes of the constituent lcm families - 
in particular the root notes of 8@0,5 which sit as branching points for two sub trees with a shared leaf node of 24@0.
Perhaps this ambivalence between two closely adjacent lcm families is the source of the swingy sound.

### Harmonic major as a junction

When allowing smaller bridges with `--min-subset-notes 4` we find the **harmonic major**. 

Take `P_A = 15@0 = {0 1 3 5 8 9 10}`
and `P_B = 15@5 = {1 2 3 5 6 8 10}`. They share

$$
S = 5@5 = \{1\;3\;5\;8\}
$$

Their union is

$$
15@0 \cup 15@5 = \{0\;1\;2\;3\;5\;6\;8\;9\;10\}
$$

This looks similar to the bebop dominant and the blues.
Instead of mixing two lcm 24 placements from two different branches (8@0,5) we mix two lcm 15 placements from the same distinct branches but less directly since we come from the tetrad instead of the hexad.

This time however *both* sides are `lcm-15`, so *both* collapse keys drop — key `8` from `15@0` and key `1` from
`15@5`:

$$
15@0 \cup 15@5 \;\setminus\; \{1,\;8\} \;=\; \{0\;2\;3\;5\;6\;9\;10\}
$$

This necklace is **harmonic major**. 
Where harmonic minor drops a single collapse key from a one-sided collapse,
harmonic major drops one from each side of a symmetric `lcm-15 · lcm-5 · lcm-15` junction.

Loosening the floor further to `--min-subset-notes 3` admits bare triad bridges, but these only
generate 8-, 9- and 10-note chromatic clusters that aren't obvious traditional scales, so we leave them aside.

**set** dropdown, **Generate** a chord, and **Play** a melody drawn from it.

### Junctions on the placement graph

Every junction above is two placements sharing a subset `S`, and `S` is exactly the node where the two
meet walking *down* the [extended triad placement graph](/docs/music/placements) — the graph of which
placements contain the central triad `4@0 = {0 4 7}`. Because that graph is drawn at one fixed
anchoring, we transpose each junction by some offset `t` to land its constituents on graph nodes
(recall `3 ≅ 4`, so a `3@k` bridge *is* the triad node `4@0`, and an `lcm-5` bridge is the tetrad node
`5@4`). Sorted by how deep the shared bridge sits in the graph:

| Junction | transposed onto the graph | bridge node |
| --- | --- | --- |
| harmonic minor | `15@11 · 18@2 · 24@0` | `18@2` hexad |
| melodic minor | `15@11 · 18@2 · 24@7` | `18@2` hexad |
| bebop dominant | `24@0 · 18@7 · 24@5` | `18@7` hexad |
| harmonic major | `15@11 · 5@4 · 15@4` | `5@4` tetrad |

The deeper the bridge, the less the two placements overlap and the larger, more chromatic their union.
The three primary scales — harmonic minor, melodic minor and bebop dominant — all bridge on the
**hexad** `18@2`/`18@7`, where the graph draws a direct edge from the hexad to each partner
(`18@2 → 15@11`, `18@2 → 24@0`), so the union adds only a note or two. Harmonic major falls one level
deeper, to the **tetrad** `5@4`, where `P_A` and `P_B` overlap less. Deeper still is the bare **triad**
`4@0` at the bottom of the graph, where the two placements share almost nothing and the union balloons
to the eight-, nine- and ten-note chromatic clusters we set aside.

This is the privilege we conjectured for the big bridging families back in
[the principles](#the-principles-of-chord-progressions): restrict the shared subset to the `lcm-18`
hexad (using `--min-subset-notes`) and only the three primary scales survive.
With the tetrad comes harmonic major and with triads chromatic scales.

To trace any row yourself, pick its bridge node in the graph and walk up. For harmonic minor
(`15@11 · 18@2 · 24@0`), start at the hexad `18@2` and climb its two direct edges — `18@2 → 15@11` on
one side, `18@2 → 24@0` on the other — then union the two heptads and drop the collapse key.

Let's look at some more examples from traditional music.

## Example Chord Progressions
Using the `progression` command we can enumerate all possible progressions between two chords.
Let's use this to analyze some chord sequences.

### C F G
A very common "[three chord song](https://en.wikipedia.org/wiki/Three-chord_song)", C F G is the I, IV, V progression of the major scale.

Expressed in placements, using key 0 for key c, the major scale is 24@0 with C=4@0, F=4@5 and G=4@7. 
Looking at the progressions between the chords we find:
* C=`0 4 7` and F=`0 5 9` are both contained by 8@5.
* F and G=`2 7 11` are contained by 24@0. (Interesting subsets include e.g. 8@5->4@0->8@0 and 18@7->24@0 which move between the 8@0 and 8@5 branch.)
* G and C are in 8@0.

Given these observations the main mechanism might be the superset principle within lcm 8 which contains two major triads, explaining the I->IV and V->I movement. 
The IV->V is a larger move, either seen as a superset principle move withing 24@0 (which contains all the three chords), or as a subset principle move shifting the chords from the 8@5 branch to the 8@0 branch.

### C to Em
C -> Em has both superset and subset progressions.
* C=`0 4 7` and Em=`4 7 11` are both contained by 8@0 (and by its supersets 24@0 and 24@7), so the superset principle applies.
* As a subset move, C's 24@7 and Em's 15@6 share the bridge 18@9 (24@7->18@9->15@6).

The simplest reading is the superset principle within lcm 8, exactly as for the major triads in C F G. 
The difference in feel could be that where C is the triad 4@0, Em=`4 7 11` is not itself a small LCM family (subset of 8@0 / 24@0) so the minor chord has no fundamental of its own within the shared pattern.

### C to B
C -> B has only subset progressions.
* The pragmatic path is C's 24@7 to B's 15@6 through the shared bridge 18@9 (24@7->18@9->15@6). This is the harmonic minor move.
* C is also contained by 15@11, sharing 5@11 with 15@6, but key 7 of C is the collapsing key of 15@11 so it is unclear if this path is actually used - i.e. does the brain infer progressions using unstable placements?

15@6 also contains Em=`4 7 11`, so B lands on the very placement we reached for C→Em — B is the minor-flavoured chord of that same 15@6 branch.

### C to Cm
C -> Cm has only subset progressions.
* Among the origins we see 8@5, 15@4,7, 18@7, 24@0,5 - this is basically the 8@5 extended placement graph with 8@5, 15@4, 18@7, 24@0,5. 
The exception is 15@7 belonging to 8@8 - if 15@7 was stable with key 3 then this progression would be a superset progression.
* Among the targets we see 8@8, 15@2, 18@5,10, 24@3,8,10 - this is basically the 8@8 extended placement graph with 8@8, 18@10, 24@3,8.
The exception is 15@2, 18@5 and 24@10 belonging to the @3 branch above 4@3.

From this it looks like the progression could be a superset progression within 15@7, but is blocked by the unstable target placement.
Instead it looks like movement from 15@7 to 15@2 via 4@3, and indeed it does sound nice with a mel@0 (15@2 based) finish.
This is similar to the intro example of C -> Eb (4@3) where we could use 15@7 as a superset bridge to land in 18@10.
